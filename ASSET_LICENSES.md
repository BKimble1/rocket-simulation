# Asset licences and provenance

Every file served by the application is either original to this project or listed here with
its source, author, licence, modifications and local path. No asset is hotlinked at runtime.
No imported asset carries third-party branding (each image was inspected; the Earth, Moon and
star maps contain no marks).

## Original to this project

| Asset | Path | Notes |
|---|---|---|
| KIMBLE symbol, KIMBLE wordmark lockups, ONE / FAB wordmark | `public/brand/*.svg`, `src/brand/logoPaths.ts` | Original vector artwork generated by `tools/brand/build_logo.py`. The symbol is hand-authored path geometry. The wordmarks are glyph outlines of **Archivo** (Omnibus-Type, SIL Open Font License 1.1) set and tracked by the script; using outlines of an OFL font in a logo is permitted by the OFL (the artwork is not a font). |
| Vehicle, engines, spacecraft, station, launch site, hangar geometry | `src/scene/**` | Procedural geometry written in TypeScript (the reproducible source), no imported models. |
| Livery and decal textures | generated at runtime from `src/brand/logoPaths.ts` | Painted onto canvases in the browser. |
| Procedural material maps (brushed metal, weave, crinkle, noise) | `src/scene/materials.ts` | Generated at runtime. |
| Sound effects | `src/audio/engine.ts` | Synthesized with the Web Audio API at runtime; no recordings. |
| Narration audio | `public/narration/<version>/*.mp3` | Generated offline from the project's own script (`src/content/narration.json`) by the Kokoro-82M text-to-speech model (see below). |

## Narration tooling and model (offline, not shipped to the browser)

`tools/narration/` is reused from the author's FAB / ONE project (see its README). Model and
dependencies, with licence texts in `tools/narration/LICENSES/`:

| Component | Licence |
|---|---|
| Kokoro-82M v1.0 weights and voices (hexgrad), ONNX export in `expo-kokoro@1.1.9` (npm) | Apache-2.0 (model), MIT (package) |
| misaki (G2P) | Apache-2.0 |
| espeak-ng (via espeakng-loader) | GPL-3.0, used as a separate build-time tool, not distributed with the app |

The generated narration audio is labelled in the interface as a synthesized voice.
